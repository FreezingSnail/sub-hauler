Choose the repository root or the story folder. The editor reads scenes.json, missions.json, dock_hints.json and art.png.

Dock hints — all berths, all completion points

This grid is campaign-wide, not filtered by the selected scene. Rows are berths; columns are campaign completion points from FRESH through HOME. Each cell is the line that berth shows at that point. Selecting a cell only changes the station preview.

Select a hint cell.

Hint text must be A-Z, 0-9, space, colon, period, slash, apostrophe or hyphen; 20 characters maximum. Duplicate lines are allowed.

Scene and card counts are fixed; this editor exposes text fields only. Writes only canonical JSON through the browser file handles. After saving, run make gen. If file:// blocks the directory picker, run make editor and open http://localhost:8000/docs/story-editor.html. The read-only review page is story-sketchbook.html.
